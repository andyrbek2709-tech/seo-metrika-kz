# Навык: Google Trends (относительный интерес)

## Назначение
Бесплатно (без аккаунта/карты) сравнить, **какие темы и запросы популярнее в поиске
Google** в Казахстане (и др. регионах). Метрика — относительный интерес 0–100 внутри
сравнения. Отвечает на вопрос «где больше» **относительно**; абсолютных чисел не даёт —
для них нужен `google-kwp` (Keyword Planner, аккаунт Google Ads).

Принцип WAT: выбор фраз и выводы — в чате; `scripts/trends_import.py` только парсит
CSV-экспорты Trends и сводит их в `.xlsx`.

## Ключевое ограничение и обход: анкор
Google Trends сравнивает максимум **5 фраз за раз** и нормирует их **внутри** этого
сравнения (топ = 100). Фразы из разных сравнений напрямую несопоставимы. Обход:
в каждый батч включают одну общую **фразу-анкор**; скрипт пересчитывает каждый файл по
анкору и приводит всё к единой шкале. Анкор — умеренно популярная стабильная фраза
(для нашего засева подходит `проектная документация`).

## Инструмент
`scripts/trends_import.py` — импорт `multiTimeline.csv`.

| Флаг | Назначение |
|---|---|
| `--csv f1 [f2 …]` | один или несколько экспортов из trends.google.com |
| `--anchor "фраза"` | общий анкор для кросс-файловой нормировки (если ≥2 батчей) |
| `--out path.xlsx` | результат |

Колонки вывода: `запрос, относит_интерес (0–100), нормировано`. Сортировка по интересу.

## Сценарий: «где больше» по KZ за 4 батча
1. trends.google.com → регион **Казахстан**, период **последние 12 мес**.
2. Внутри арены сравни её фразы (+ анкор `проектная документация`), «Скачать» →
   `A.csv` (арена A), `B.csv` (арена B), `C.csv` (арена C). Анкор в каждом файле.
3. Сведи:
```bash
python scripts/trends_import.py --csv A.csv B.csv C.csv \
  --anchor "проектная документация" --out kz_trends.xlsx
```
4. (Опц.) 4-й батч: лидеры арен A/B/C в одном сравнении → прямое «где больше» без нормировки.

## Интерпретация
- 0–100 — **относительная** доля, не объём. «50» = вдвое меньше интереса, чем у топа (100).
- Низкий абсолютный спрос ниши Trends покажет как шум (много нулей/`<1`) — это сигнал,
  что тему лучше мерить через Keyword Planner или брать шире.
- Региональный срез (по областям KZ) и «Похожие запросы» в Trends — источник расширения
  семантики; экспортируй отдельно при необходимости.

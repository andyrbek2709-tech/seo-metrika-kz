# Настройка: Google Trends (без аккаунта и карты)

Google Trends бесплатен и не требует входа, аккаунта Google Ads или карты.

## Как выгрузить CSV

1. Открой **https://trends.google.com/trends/explore**
2. Регион: **Казахстан**. Период: **Последние 12 месяцев** (или 5 лет для тренда).
3. В строку «Добавить запрос» введи до **5 фраз** для сравнения. Одной из пяти всегда
   делай **анкор** — общую фразу для всех батчей (рекомендуется `проектная документация`).
4. На карточке графика **«Динамика популярности»** (Interest over time) нажми кнопку
   **«Скачать»** (значок стрелки вниз) → сохранится `multiTimeline.csv`.
5. Переименуй осмысленно (`A.csv`, `B.csv`, …), чтобы не перезаписывались.

## Метод анкора (зачем)

Trends нормирует значения **внутри одного сравнения**: топовая фраза = 100, остальные —
доля от неё. Поэтому «50» в одном батче и «50» в другом — это разные абсолютные величины.
Чтобы сравнивать фразы из разных батчей, в каждый батч кладут **один и тот же анкор**;
`trends_import.py --anchor "…"` пересчитывает каждый файл так, чтобы анкор = 100, и сводит
всё в единую шкалу.

Требования к анкору:
- встречается во **всех** батчах с одинаковым написанием;
- умеренно популярен (не нулевой и не подавляюще доминирующий), иначе нормировка шумит.

## Что ещё экспортировать (опционально)

- **«По субрегионам»** (geoMap.csv) — распределение по областям KZ.
- **«Похожие запросы»** (relatedQueries.csv) — кандидаты на расширение семантического ядра.

Эти файлы `trends_import.py` не обрабатывает (он про динамику/средний интерес) — смотри их
глазами в чате или приноси содержимое для анализа.

## Ограничения

- Метрика относительная (0–100), не «N запросов/мес». Абсолют — только через `google-kwp`.
- Узкие B2G-ниши могут давать много `<1`/нулей — это и есть ответ «спроса в Google мало»,
  но для точной оценки лучше Keyword Planner.
- Частые запросы к trends.google.com из автоматики блокируются — поэтому путь ручной (экспорт).

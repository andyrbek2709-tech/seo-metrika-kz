# Навык: Product Discovery (спрос → идеи продуктов)

## Назначение

Соединяет четыре шага в один воспроизводимый воркфлоу:

1. **Генерация запросов** — из коротких «семян» строим веер формулировок по типам намерения.
2. **Съём спроса** — сколько и что реально ищут в Google (через навык `google-kwp` / DataForSEO).
3. **Анализ рынка** — кластеризуем в темы, читаем что аудитория **реально хочет** (jobs-to-be-done и боль).
4. **Планирование** — ранжированный отчёт идей приложений/инструментов на Claude.

Базовый домен — **проектирование ПД + прохождение Госэкспертизы** (KZ). Аудитория:
проектировщики, ГИПы, эксперты Госэкспертизы. Навык применим и к другой нише — меняются
семена и словарь тем.

**Принцип WAT** (Workflow + AI Thinking): механику (раскрытие шаблонов, парсинг, суммы,
ранжирование) делают скрипты; смысловые решения (какие семена, что значат цифры, какие
продукты строить) — в чате. Скрипт даёт каркас, аналитик даёт смысл.

## Инструменты

| Скрипт | Что делает | Когда |
|---|---|---|
| `scripts/expand_seeds.py` | семена → кандидаты-запросы по намерениям | шаг 1 |
| `scripts/cluster_demand.py` | .xlsx спроса → темы рынка с частотой и топами | шаг 3 |
| `assets/report_template.md` | каркас итогового отчёта с идеями | шаг 4 |

Намерения в `expand_seeds.py`: `info` (что это/состав), `howto` (как пройти/сделать),
`cost` (цена/сроки), `service` (заказать/услуги), `problem` (ошибки/замечания/отказ —
**самый ценный сигнал для продукта**), `geo` (рк/казахстан/алматы/астана).

## Рабочий процесс

### Шаг 1 — Сгенерировать запросы и варианты

Старт — `../google-kwp-skill/seeds_pd_gosexpertiza.txt` (темы: разработка ПД + Госэкспертиза).
Не хватает — допиши семена под конкретный вопрос discovery.

```bash
# полный веер кандидатов (для API-съёма или широкого охвата)
python scripts/expand_seeds.py --seeds ../google-kwp-skill/seeds_pd_gosexpertiza.txt \
  --out candidates.txt

# узко: только коммерческий спрос и боль + гео РК
python scripts/expand_seeds.py --seeds ../google-kwp-skill/seeds_pd_gosexpertiza.txt \
  --intents cost service problem --geo --group --out candidates.txt
```

Полный веер даёт сотни кандидатов — это нормально для API-съёма через DataForSEO. Если
снимаешь вручную (CSV из веб-Планировщика), отбери в чате 30–60 самых осмысленных строк.
Помни: лишний кандидат дешевле пропущенного спроса.

### Шаг 2 — Снять спрос (делегируй навыку google-kwp)

Этот навык **не ходит в API сам** — он оркеструет. Источник — Google через `google-kwp`:

- **Объёмы + идеи (рекомендуется)** → `gkp_client.py ideas --backend dataforseo` —
  абсолютные объёмы, конкуренция и ставки по KZ через DataForSEO, без аккаунта Google Ads
  и без карты (нужен `~/dataforseo.yaml`).
- **Только объёмы по точным фразам** → `gkp_client.py volume`.
- **Бесплатно вручную** → `gkp_client.py import` CSV из веб-Планировщика Google.

Результат — `.xlsx` с единой схемой (`запрос, тип, ср_частота_мес, …`). Чтобы сравнить
KZ vs РФ, прогоняй один и тот же список кандидатов на разных гео (`--geo 2398` / `2643`).

Если данных ещё нет — честно скажи об этом и предложи сначала снять спрос (через `google-kwp`),
не выдумывай цифры. Можно показать каркас анализа на пустом шаблоне.

### Шаг 3 — Кластеризовать в темы рынка

```bash
python scripts/cluster_demand.py --xlsx ../kz_google.xlsx --out themes.xlsx
# несколько файлов сразу (например KZ и РФ):
python scripts/cluster_demand.py --xlsx ../kz_google.xlsx ../ru_google.xlsx --top 8
```

Даёт темы с суммарной частотой, долей и топ-запросами + лист «Прочее» (не попавшее в
темы — сырьё для новых тем, смотри глазами). Словарь тем по умолчанию заточен под домен;
свой передаётся через `--themes theme.json` (тема → список ключей-подстрок).

### Шаг 4 — Анализ + идеи продуктов (в чате, по шаблону)

Скопируй `assets/report_template.md` и заполни поверх данных. Ядро навыка — здесь, и это
работа мышления, а не скрипта:

- **Что реально хотят** — за каждой крупной темой назови задачу (JTBD) и боль. Запросы
  с намерением `problem` («замечания», «отказ», «ошибки», «доработка») — прямой крик о
  проблеме, которую продукт может снять. Это ценнее голого объёма.
- **Идеи продуктов на Claude** — каждую привязывай к запросам, которые её оправдывают.
  Ранжируй по: спрос × боль × fit-с-Claude (работа с текстом/документами/нормами —
  сильная сторона LLM) ÷ сложность MVP. Для топ-1–2 — абзац про MVP (вход/выход, где
  Claude в центре, первый экран).
- **Честность** — спрос ≠ готовность платить. В «следующих шагах» предложи валидацию
  топ-идей разговором с 3–5 проектировщиками/экспертами.

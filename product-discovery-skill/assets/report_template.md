## 4. Идеи продуктов на Claude (ранжировано)

_Каждая идея привязана к запросам, которые её оправдывают. Скоринг 1–5:_
- **Спрос** — объём/частота темы из раздела 2.
- **Боль** — острота проблемы (есть ли intent=problem запросы).
- **Fit с Claude** — насколько задача = работа с текстом/документами/нормами (сильная сторона LLM).
- **Реализуемость** — насколько MVP можно собрать быстро.
- **Приоритет = Спрос × Боль × Fit / сложность** (словами, не формулой ради формулы).

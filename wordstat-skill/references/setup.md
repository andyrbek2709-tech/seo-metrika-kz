# Настройка доступа: Яндекс Wordstat (Yandex Direct API)

Делается один раз. Без реального аккаунта Яндекс.Директа с доступом к API
Wordstat-отчёты недоступны.

## Что нужно собрать

| Секрет | Где взять |
|---|---|
| OAuth-токен | приложение в Яндекс OAuth + авторизация под аккаунтом Директа |
| аккаунт Яндекс.Директа | https://direct.yandex.ru (логин, под которым работает API) |

## 1. Регистрация приложения и токен

1. Создай приложение: https://oauth.yandex.ru/client/new → выдай ему права на
   **Яндекс.Директ (API)**. Получишь `client_id` и `client_secret`.
2. Получи OAuth-токен под нужным аккаунтом Директа (Authorization Code Grant):
   открой `https://oauth.yandex.ru/authorize?response_type=token&client_id=ВАШ_CLIENT_ID`,
   авторизуйся — токен вернётся в URL-фрагменте `#access_token=...`.
3. (Для агентств/MCC указывается клиент через логин — в этом навыке не используется.)

## 2. Файл конфигурации `~/yandex-direct.yaml`

```yaml
token: "ВАШ_OAUTH_ТОКЕН"
```

Клиент ищет токен в таком порядке: флаг `--token` → env `YANDEX_DIRECT_TOKEN` →
файл `~/yandex-direct.yaml` (или путь из `YANDEX_DIRECT_CONFIGURATION_FILE_PATH`).
Парсер берёт строку `token: ...` — PyYAML не требуется.

## Подводные камни

- **Доступ к API Директа** выдаётся не сразу — у нового аккаунта может потребоваться
  заявка/активация. Без доступа `CreateNewWordstatReport` вернёт ошибку.
- **Лимит 10 фраз** на один Wordstat-отчёт — клиент чанкует засев сам.
- **Отчёт асинхронный**: создаётся → встаёт в очередь → опрашивается до статуса `Done`.
  Клиент опрашивает каждые 5 c (таймаут 300 c) и удаляет отчёт после чтения.
- **Очередь отчётов** ограничена — клиент обрабатывает чанки последовательно.
- Используется **Yandex Direct API v4 Live** (метод Wordstat-отчётов) — канонический способ
  получить частотность через официальный API. Это устаревающий контур; при отключении
  переключиться на актуальный Wordstat API Яндекса (эндпоинт меняется в `wordstat_client.py`,
  константа `API_URL`).
- Не коммить `yandex-direct.yaml` и токен в git. Уже закрыто `.gitignore`.

# Навык: Яндекс Wordstat (Yandex Direct API)

## Назначение

Получение оценки спроса в поиске Яндекса: **абсолютная** среднемесячная частотность
(показы Wordstat) и связанные запросы для расширения семантики. Гео-таргет на Казахстан
(по умолчанию), РФ и страны СНГ. Применяется для семантического ядра и **discovery-исследования
спроса** на русскоязычном рынке.

Преимущество Wordstat перед Google Keyword Planner — точные числа показов даже без
рекламного бюджета и богатый длинный хвост профессиональных запросов. Минус — нет рекламных
метрик (конкуренция, ставки).

Принцип WAT: AI-решения — в чате; вызовы API и запись Excel делает
`scripts/wordstat_client.py`. Формат вывода **идентичен** навыку `google-kwp` —
результаты двух источников можно сравнивать и сливать.

---

## Два пути доступа

**Путь A — веб-выгрузка (рабочий, рекомендуется).** https://wordstat.yandex.ru открывается
с обычным аккаунтом Яндекса — **без Директа и без Госуслуг**. Даёт абсолютные числа
запросов и разбивку по регионам Казахстана. Ставишь регион = Казахстан, ищешь фразу,
жмёшь «Скачать» → файл прогоняешь командой `import`. Зависимость — только `openpyxl`.

**Путь B — Yandex Direct API (`ideas`/`volume`).** Автоматический батч-съём через OAuth-токен
Директа в `~/yandex-direct.yaml`. Но регистрация приложения Директа из Казахстана упирается
в подтверждение через Госуслуги РФ — путь **заблокирован**, пока нет доступа к API.
См. `references/setup.md`.

## Инструмент

`scripts/wordstat_client.py` — 3 подкоманды. Вывод только `.xlsx`.

| Команда | Что делает | API/токен |
|---|---|---|
| `import` | веб-выгрузка «Скачать» (.xlsx/.csv) → наша схема | **не нужен** |
| `ideas` | расширяет засев связанными запросами + частоты | нужен |
| `volume` | частоты только по своим фразам, без расширения | нужен |

`import`: `--file <выгрузка.xlsx|.csv>` `--out path.xlsx`. Парсит вкладку «Топы запросов»
(оба блока — «со словом» и «похожие»), автоопределяет колонки «фраза»/«запросов в месяц»,
дедупит и сортирует по частоте.

`ideas`/`volume`: `--phrases "a" "b"` / `--phrases-file f.txt`, `--token <OAuth>` (или env),
`--geo <id...>` (по умолч. 159 = Казахстан), `--top N`, `--out path.xlsx`.
ID регионов — `references/geo_targets.md`.

Колонки вывода (как в google-kwp): запрос, тип (засев/идея), ср_частота_мес,
конкуренция, индекс_конкуренции, ставка_верх_TOP, ставка_низ_TOP. У Wordstat нет
рекламных метрик — колонки конкуренции и ставок пустые. Сортировка по частоте.

## Сценарии

### 0. Веб-выгрузка → наша схема (рабочий путь, без API)
1. Открой https://wordstat.yandex.ru, войди обычным аккаунтом Яндекса.
2. **Регион → Казахстан** (иначе числа будут по всему рынку, в основном РФ).
3. Введи фразу засева, вкладка **«Топы запросов»**, нажми **«Скачать»** → `phrase.xlsx`.
4. Приведи к общей схеме:
```bash
python scripts/wordstat_client.py import --file ~/Downloads/phrase.xlsx --out ../kz_yandex.xlsx
```
Несколько фраз: качай по очереди, прогоняй каждую в отдельный файл, в чате сольём.
Вкладка **«Регионы»** даёт абсолютные числа по областям KZ — приноси в чат для гео-разбора.

### 1. Семантическое ядро под Яндекс (KZ) — через API (пока заблокировано)
```bash
python scripts/wordstat_client.py ideas \
  --phrases "пожарная сигнализация" "проектная документация" \
  --out core_yandex.xlsx
```

### 2. Discovery: сравнить спрос KZ vs РФ
```bash
python scripts/wordstat_client.py ideas --phrases-file seeds_discovery.txt \
  --geo 159 --out kz.xlsx
python scripts/wordstat_client.py ideas --phrases-file seeds_discovery.txt \
  --geo 225 --out ru.xlsx
```
Дальше в чате: сопоставить частоты по аренам → найти «gap»-запросы → гипотезы продукта.

### 3. Кросс-источник: Яндекс vs Google
Прогони те же `seeds_discovery.txt` здесь и в навыке `google-kwp`. Где источники
расходятся по объёму/составу запросов — там видно, на каком рынке и в какой
поисковой системе ниша живее. Идентичный формат `.xlsx` позволяет слить их в один разбор.

## Интерпретация

- Wordstat «Показы» — сколько раз запрос (в широком соответствии) показывался за месяц;
  это спрос пользователей, а не рекламная оценка.
- Конкуренция/ставки пустые — это нормально: Wordstat их не отдаёт (бери их из google-kwp).
- Для KZ помни: доля Яндекса в Казахстане мала — низкая частота по гео 159 не означает
  отсутствие рынка, сравнивай с Google по тем же фразам.
- Профессиональный русскоязычный хвост у Яндекса обычно богаче — полезно для расширения ядра.
